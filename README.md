# The Curator

## Project Description

The Curator is an AI-powered blogging and social platform built using the MERN stack.
It aims to combine content creation, social interaction, and intelligent AI assistance into a single modern web application.

The platform will include features like blog publishing, user interactions such as likes, comments, and follows, real-time notifications, and a subscription-based AI writing assistant.

This repository currently contains the initial project structure and will be developed incrementally.
